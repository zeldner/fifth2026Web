יצירת הפרויקט ובחירת מנוע SWC

npm create vite@latest my-app -- --template react-swc
The Engine: SWC (Speedy Web Compiler)
קומפיילר מודרני מבוסס Rust. מהיר פי 20 עד 70 מ-Babel המסורתי! כאשר מבצעים שינוי ושומרים (Save), הקוד מתעדכן בדפדפן כמעט מיידית ללא עיכוב (Babel עשוי לייצר השהיה קלה).
חיסרון: כלי חדש יחסית, ולכן יש לו פחות פלאגינים ייחודיים (niche plugins).
2

החלטות ארכיטקטורה: מניעת הפשטה (No React Compiler / Rolldown)

למה בחרנו NO עבור React Compiler (בעבר React Forget)?
הכלי מבצע Memoization אוטומטי למשתנים ולפונקציות כדי לחסוך עבודת אופטימיזציה למפתחים בכירים. אך עבור לימוד – הוא מסתיר את מנגנון ה-Re-renders ומחזור החיים (Lifecycle)! אנחנו רוצים לעשות טעויות, לראות מתי קומפוננטה מתרנדרת מחדש ולהבין את הבסיס לעומק.

למה בחרנו NO עבור Rolldown?
Rolldown הוא כלי ניסיוני (Beta) שנבנה להחליף מנועים קיימים ב-Vite. בחירה ב-YES עלולה לחשוף אותנו לקריסות ובאגים לא צפויים. בחרנו ב-NO כדי לקבל סביבה יציבה ובדוקה (battle-tested).
3

שליטה בטרמינל: דילוג על הרצה ראשונית אוטומטית

בשאלה "Install with npm and start now?" בחרנו NO.
הסיבה ההנדסית: בחירה ב-YES מריצה את שרת הפיתוח ונועלת את חלון הטרמינל. מצב זה ימנע מאיתנו להתקין ספריות נוספות (כמו Tailwind) ללא עצירה מאולצת (Ctrl + C).
4

התקנת תלויות ואינטגרציית Tailwind CSS v4

cd my-app npm install npm install tailwindcss @tailwindcss/vite
ביצוע npm install מקים את תיקיית node_modules. לאחר מכן אנו מתקינים ישירות את הפלאגין הרשמי של Tailwind v4 עבור מנוע Vite.
5

קונפיגורציית שרת (vite.config.js) וייבוא סגנונות

// vite.config.js import tailwindcss from '@tailwindcss/vite' export default defineConfig({ plugins: [react(), tailwindcss()], server: { port: 3001, open: true, // Auto-open browser on run }, }) /* src/index.css */ @import "tailwindcss";
קביעת הפורט ל-3001 מונעת התנגשויות ברירת מחדל (פורט 5173/3000), והדפדפן נפתח עצמאית ברגע הרצת השרת.

דפוס תכנון קומפוננטות אופן המימוש משמעות הנדסית
Atomic Components HelloWorldJS, GreetingJS (#1, #2, #3) קבלת Primitive Props פשוטים (מחרוזות) רכיבים טהורים (Pure Components) ללא תלויות צדדיות

Event Callback ButtonContainer > ActionButton (#5) העברת פונקציה כ-Prop (onClick) אירוע שנוצר בבן מפעיל לוגיקה שהוגדרה בקומפוננטת האב
Composition CardWrapper (#11) שימוש ב-props.children מעטפת תצוגה כללית שאינה צריכה לדעת מראש מה ירונדר בתוכה
