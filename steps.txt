1. Create the Vite + React Project
------------------------------------------------------------------------------
Run in terminal:
    npm create vite@latest

Interactive prompts:
    - Project name: my-app
    - Select a framework: React
    - Select a variant: JavaScript + SWC
        * Why SWC (Speedy Web Compiler)?
          Written in Rust, SWC compiles JSX 20x-70x faster than Babel, giving
          near-instant Hot Module Replacement (HMR) when you save a file.
    - Enable "React Compiler"? -> Select NO
        * Why NO for learning?
          React Compiler auto-memoizes components and values behind the scenes.
          Turning it OFF lets students see natural component re-renders and
          understand React's rendering lifecycle directly.
    - Use experimental Rolldown bundler (if prompted)? -> Select NO
        * Keeps the stable, battle-tested Vite build pipeline.
    - Install with npm and start now? -> Select NO
        * Selecting NO keeps the terminal free so we can install Tailwind CSS
          before launching the dev server.

2. Install Dependencies & Tailwind CSS v4
------------------------------------------------------------------------------
    cd my-app
    npm install
    npm install tailwindcss @tailwindcss/vite

Configure vite.config.js:
    import { defineConfig } from 'vite'
    import react from '@vitejs/plugin-react'
    import tailwindcss from '@tailwindcss/vite'

    export default defineConfig({
      plugins: [react(), tailwindcss()],
      server: {
        port: 3001,
        open: true,
      },
    })

Configure src/index.css:
    @import "tailwindcss";

    @layer base {
      body {
        margin: 0;
        min-width: 320px;
        min-height: 100vh;
        background-color: #f1f5f9;
        color: #0f172a;
      }
    }

3. Wire AppComponents.jsx in src/main.jsx
------------------------------------------------------------------------------
To display the Practice 5 Dashboard instead of Vite's starter page, update
src/main.jsx to import AppComponents:

    import { StrictMode } from 'react'
    import { createRoot } from 'react-dom/client'
    import './index.css'
    import App from './AppComponents.jsx'

    createRoot(document.getElementById('root')).render(
      <StrictMode>
        <App />
      </StrictMode>,
    )

Start the development server:
    npm run dev

4. Recommended Browser & VS Code Extensions
------------------------------------------------------------------------------
- Chrome Extension:
    * React Developer Tools (inspect component tree & live props in DevTools)
- VS Code Extensions:
    * ES7+ React/Redux/React-Native snippets
        - Use `rfce` or `rafce` to scaffold a Functional Component.
        - Note: In React 19, delete the unused `import React from 'react'` line
          if the snippet adds it.
        - Avoid Class Component snippets (like `ccc`) — modern React uses
          functional components exclusively.
    * Tailwind CSS IntelliSense (autocomplete & hover previews for utility classes)
    * React Component Tree / Omlet for VS Code (visualizes parent-child hierarchy)

5. Complete Summary of All 14 Component Examples (src/components/firstT/)
------------------------------------------------------------------------------
- #1  HelloWorldJS1.jsx: First functional component & JSX basics.
- #2  GreetingJS2.jsx: Passing props & parameter destructuring.
- #3  GreetingJS3.jsx: ES6 default prop values & JS expressions inside `{}`.
- #4  UserList4.jsx + ProfileCard4.jsx: Parent-Child composition & mapping arrays with stable keys.

- #8  VisibilityController8.jsx + TogglebleText8.jsx: Conditional rendering with `Boolean(isVisible) && <JSX />`.
- #9  AlertContainer9.jsx + Alert9.jsx: Dynamic styling via complete Tailwind class lookup dictionaries.
- #10 DynamicMenu10.jsx: Data-driven navigation menu & `aria-current="page"`.
- #11 CardWrapper11.jsx: Component composition using `children` & named `footer` slot props.
- #12 UserStatus12.jsx: Ternary operator (`? :`) & boolean status badges.
- #13 ArticleLayout13.jsx: React Fragments (`<>...</>`) to avoid unnecessary wrapper `<div>` nodes.
- #14 ProductCard14.jsx: Passing objects as props, early guard clauses & default fallbacks.
